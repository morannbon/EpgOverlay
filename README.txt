# EpgOverlay v1.0.1

## v1.0.1 の主な変更

- サブチャンネルの番組情報補完を改善しました。
- TVTestのEPGデータで番組情報の共有が指定されている場合、参照先の番組情報を利用して補完できるようになりました。
- サブチャンネル自身にタイトルが記録されていない番組でも、正式な共有情報が存在する場合は補完できるようになりました。

TVTestのEPGデータを利用して、TvAIr本体で取得できなかった番組枠や不足している番組情報を補完するTvAIr用プラグインです。

## 動作環境

**TvAIr 1.2.2 以上が必要です。**

- Windows
- TvAIr 1.2.2 以上
- TVTest
- TVTestで作成されたEPGデータ
- .NET 8
- x64 / x86

---

## EpgOverlayとは

EpgOverlayは、TvAIr本体のEPG取得を置き換えるものではありません。

TvAIr本体で取得できた番組情報を優先し、本体で取得できなかった番組枠や不足している番組情報だけをTVTestのEPGデータから補完します。

TvAIr本体だけで番組表が完成している場合、EpgOverlayが追加する番組枠はありません。

TVTestのEPGデータは補完用として使用し、TvAIr本体の番組データベースそのものは変更しません。

## 主な機能

- TvAIr本体に存在しない番組枠をTVTestのEPGデータから補完
- TvAIr本体で不足している概要、詳細、ジャンル等を補完
- TVTestのEPGデータで番組情報の共有が指定されているサブチャンネルを補完
- TvAIrで有効になっているサービスのみを番組表へ反映
- EPGデータ更新後の番組表反映
- 読み取り途中の不完全なEPGデータを採用せず、直前の正常な内容を維持
- 有効 / 無効の切り替え
- TvAIrのライト / ダークテーマに追随
- 外部ネットワーク通信なし
- TvAIr本体の番組データベースへの書き戻しなし

## 必要なEPGデータ

EpgOverlayでは、TVTestが保存したEPGデータファイルを使用します。

標準的なTVTest環境では、ファイル名は次のようになります。

```text
EpgData
```

拡張子はありません。

EpgOverlayはファイル名や拡張子を固定せず、選択されたファイルの内容を読み取ります。TVTest側で実際に使用しているEPGデータファイルを指定してください。

## ビルドとインストール

### 必要な環境

- Visual Studio 2022
- .NET 8 SDK

### ビルド手順

1. 配布ZIPを展開します。
2. Visual Studio 2022で `EpgOverlay.sln` を開きます。
3. 使用するTvAIrと同じアーキテクチャのRelease構成を選択します。

```text
Release | x64
```

または

```text
Release | x86
```

4. ソリューションをビルドします。

生成されるDLL:

x64:

```text
EpgOverlay\bin\x64\Release\EpgOverlay.dll
```

x86:

```text
EpgOverlay\bin\x86\Release\EpgOverlay.dll
```

5. TvAIrを終了します。
6. 使用するTvAIrと同じアーキテクチャの `EpgOverlay.dll` を、TvAIrのPluginフォルダ直下へ配置します。
7. TvAIrを起動し、プラグインメニューに `EpgOverlay` が表示されることを確認します。

Pluginフォルダへ配置するのは `EpgOverlay.dll` だけです。ソース、README、設定ファイル等を配置する必要はありません。

## 初期設定

1. TvAIrを起動します。
2. プラグインメニューから `EpgOverlay` を開きます。
3. `EPGデータ` にTVTestのEPGデータファイルを指定します。
4. 必要に応じて `参照` からファイルを選択します。
5. `確認` を押して読み取り結果を確認します。
6. `有効` にチェックします。
7. `保存` を押します。

初回起動時、EPGデータのパスは空欄です。EpgOverlayがTvAIrやPC内を検索して保存先を自動推測することはありません。

## 画面の操作

### EPGデータ

TVTestのEPGデータファイルを指定します。直接パスを入力するか、`参照` から選択できます。

### 参照

TvAIrのファイル選択画面を開きます。TVTestが使用しているEPGデータファイルを選択してください。

### 確認

現在入力されているEPGデータを読み込み、解析結果を表示します。`確認` だけでは設定は保存されません。

### 保存

現在の有効状態とEPGデータのパスを保存します。

有効の場合は、EPGデータを正常に読み取れたことを確認したあと、TvAIrの番組表へ反映します。

読み取りに失敗した場合や、読み取り中にファイル内容が変化した場合は、その内容を採用せず、現在正常に使用している番組表への反映内容を維持します。

### 有効 / 無効

`有効` にして保存すると、TVTestのEPGデータを番組表の補完に使用します。

`無効` にして保存すると、保存済みのEPGデータパスは保持したまま、EpgOverlayによる番組表補完を解除します。

TvAIr本体の番組データベースは変更しません。

## 番組情報の補完について

TvAIr本体に番組が存在する場合は、本体側の番組情報を優先します。

EpgOverlayはTVTestのEPGデータを利用し、必要な部分だけを番組表へ重ね合わせます。

主な補完対象:

- 番組タイトル
- 概要
- 詳細
- ジャンル
- 番組枠

TVTest側に情報が存在しない場合、EpgOverlayが番組タイトル等を推測して生成することはありません。

## サブチャンネルについて

TVTestのEPGデータでは、サブチャンネル側の番組タイトルや詳細を直接持たず、別のサービスにある番組情報を共有している場合があります。

EpgOverlay v1.0.1では、TVTestのEPGデータ内で番組情報の共有が明示されている場合、その参照先の番組情報を利用して補完します。

局名、チャンネル番号、時刻などから番組を推測して結び付けることはありません。

## 対象サービス

EpgOverlayはTVTestのEPGデータを読み取りますが、TvAIrの番組表へ反映するのはTvAIrで有効になっているサービスです。

TvAIrで使用していないサービスを、EpgOverlayだけが番組表へ追加することはありません。

## TVTest側のEPGデータについて

EpgOverlayが補完できる内容は、TVTestのEPGデータに保存されている情報に依存します。

TVTest側で十分なEPG情報が取得されていない場合は、必要に応じてTVTestで対象チャンネルを受信し、EPGデータを更新してください。

TVTest終了時にEPGデータを書き出す環境では、TVTestを通常の終了操作で閉じてください。

## 外部通信

EpgOverlayはインターネットやLAN上の外部サービスへ接続しません。

TVTestのローカルEPGデータとTvAIr内の情報だけを使用します。外部サービスのアカウント、APIキー、ネットワーク利用設定等は不要です。

## 更新方法

1. TvAIrを終了します。
2. 新しいソースをReleaseビルドします。
3. TvAIrのPluginフォルダにある旧 `EpgOverlay.dll` を、新しい `EpgOverlay.dll` へ置き換えます。
4. TvAIrを起動します。
5. EpgOverlayを開き、設定が引き継がれていることを確認します。

通常は、保存済みのEPGデータパスと有効 / 無効設定をそのまま利用できます。

## アンインストール

1. TvAIrを終了します。
2. TvAIrのPluginフォルダから `EpgOverlay.dll` を削除します。
3. TvAIrを起動します。

EpgOverlayはTvAIr本体の番組データベースを書き換えないため、アンインストールによってTvAIr本体が取得したEPG情報が削除されることはありません。


# 過去版の更新履歴

## v1.0.0

- 初回公開版。
- TVTestのEPGデータを利用して、TvAIrの番組表で不足している番組情報を補完する機能を搭載しました。
- TvAIr本体に存在する番組を優先し、不足情報や本体に存在しない番組枠を番組表へ重ね合わせる方式に対応しました。
- TvAIr本体の番組データベースへ書き戻さず、番組表上だけで補完する方式に対応しました。
- EPGデータの確認、保存、有効 / 無効切り替えに対応しました。
- 読み取り中にEPGデータが変更された場合、不完全な内容へ切り替えず直前の正常な内容を維持するようにしました。
- TvAIrのライト / ダークテーマに対応しました。

## 注意事項

- TvAIr 1.2.2以上が必要です。
- TvAIrを終了してからDLLを更新してください。
- TVTestのEPGデータが存在しない場合は利用できません。
- EPGデータのパスが未入力の場合、確認・保存はできません。
- TVTestのEPGデータが破損している場合や、正常に読み切れない場合は反映しません。
- 読み取り途中でEPGデータが変更された場合は、その読み取り結果を採用しません。
- TVTest側に存在しない番組情報を推測して生成することはありません。
- TvAIr本体の番組データベースへの書き戻しは行いません。
- TvAIrで無効になっているサービスは番組表への補完対象になりません。
