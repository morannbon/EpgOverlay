EpgOverlay

概要
EpgOverlayは、TVTestのEPGデータを読み込み、TvAIrの番組表へ重ね合わせて表示するTvAIr用プラグインです。

TvAIr本体に番組情報がある場合は本体側の情報を優先し、不足している概要、詳細、ジャンル等をTVTestのEPGデータから補完します。
TvAIr本体に存在しない番組についても、同じ放送サービスとして確認できる範囲で番組表へ表示します。
TvAIr本体の番組データベースへの書き戻しは行いません。

インストール方法
1. Visual Studio 2022で .\EpgOverlay.sln を開きます。
2. 使用するTvAIr本体に合わせて、構成をRelease x86またはRelease x64にしてビルドします。
3. ビルド後のEpgOverlay.dllは次の場所に出力されます。

   x86版
   .\EpgOverlay\bin\x86\Release\EpgOverlay.dll

   x64版
   .\EpgOverlay\bin\x64\Release\EpgOverlay.dll

4. 使用するTvAIr本体と同じアーキテクチャのEpgOverlay.dllを、TvAIrのPluginフォルダ直下へ配置します。
5. TvAIrを再起動し、プラグインメニューからEpgOverlayを開きます。
6. TVTestのEPGデータファイルのパスを入力するか、「参照」からファイルを選択します。
7. 「確認」で読込結果を確認し、「保存」で設定を保存します。

使用方法
EPGデータ
TVTestのEPGデータファイルのパスを指定します。
「参照」ではTvAIrのファイル選択画面を使用します。ファイル名や拡張子は決め打ちせず、選択されたファイルの内容を読取時に判定します。
初回起動時は空欄です。EpgOverlayがTvAIr本体やPC環境からパスを推測して自動設定することはありません。

確認
現在入力しているTVTestのEPGデータを読み込み、解析結果を画面へ表示します。設定は保存しません。
確認後も、保存するまでは現在の有効/無効とEPGデータのパスを保持します。

保存
現在の有効状態とEPGデータのパスを保存します。
有効の場合は、TVTestのEPGデータを正常に読み取れたことを確認したうえで番組表へ反映します。
読み取りに失敗した場合は、保存済み設定と現在の番組表への反映内容を変更しません。
TVTestがEPGデータを書き換えている途中や、読み取り中にファイル内容が変化した場合も反映せず、現在の番組表を維持します。

有効 / 無効
「有効」にして保存するとTVTestのEPGデータを番組表へ反映します。
「無効」にして保存すると、設定したEPGデータのパスは保持したまま、EpgOverlayが追加した番組表情報を解除します。

注意事項
EPGデータのパスが未入力の場合は確認・保存できません。
TVTestのEPGデータの内容はTvAIr本体の番組データベースへ書き込みません。
画面の配色はTvAIrの現在のライト/ダークテーマへ追随します。
TVTestのEPGデータの形式や内容に不備がある場合、一部またはすべての番組情報を読み込めないことがあります。
複数の対象データを扱う場合、1つでも正常に読み切れなければ現在の番組表を維持します。

ライセンスおよび関連ソフトウェアについて
本プラグインは、TVTestのEPGデータをTvAIrの番組表へ重ね合わせて表示するために作成されたTvAIr用プラグインです。
TvAIr Plugin SDKおよびTvAIr本体に由来するファイルについては、TvAIr側の配布条件に従ってください。
本プラグインに含まれる独自実装部分の利用、改変、再配布は許可します。
ただし、本プラグインの利用によって生じたいかなる損害についても、作者および配布者は責任を負いません。
